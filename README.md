# FAIRY TAIL MAGIC ARENA — V7 Reference Edition

> 비공식 개인 팬 프로젝트. 사용자가 제공한 고해상도 레퍼런스 이미지를 직접 화면 자산으로 활용하는 방식으로 UI 충실도를 높인 버전입니다.

## V7에서 달라진 것

- 사용자가 제공한 `페어리 테일 매직 아레나_ 아케인 클래시` 이미지의 화면 구성과 레이아웃을 그대로 보여주는 **인터랙티브 쇼케이스 메인 화면**.
- 레퍼런스에서 분리한 나츠 / 루시 / 엘자 / 그레이 캐릭터 카드를 이용한 **클릭 가능한 캐릭터 선택 화면**.
- 닉네임 입력, 온라인 1vs1 / 1vs1vs1 / 2vs2 모드 선택, AI 난이도·상대 선택, 친구 방 코드 입장.
- 실제 서버 상태와 연결되는 **RED / BLUE 팀 대기실**, 초대 코드, 링크 복사, 팀 이동, 전투 시작.
- 실제 전투 중 상단의 전투 나가기 / 전체화면 버튼.
- 기존 V6의 서버 기반 3,600px 월드, 다층 발판, 점프 물리, 힐팩/마나/속도 아이템, 스킬, 3타 연계, AI, 온라인 대전 유지.
- 사용자가 제공한 예시를 개별 UI 이미지로 나누어 재사용. 본 프로젝트는 독립 제작된 100% 일치 픽셀 애니메이션을 포함하지 않습니다.

## 중요한 품질 한계

**메인 쇼케이스와 개별 캐릭터 카드는 제공받은 예시 이미지의 픽셀을 직접 사용합니다.** 따라서 화면이 원본과 일치해 보이는 것은 인게임 캐릭터와 배경 전체를 픽셀 단위로 새로 제작했다는 뜻이 아닙니다.

**실제 움직이는 전투는 V6의 라이브 Canvas 렌더러입니다.** 전투 HUD·도트 캐릭터·스킬 이펙트는 작동하지만, 예시 이미지의 모든 장면과 프레임을 100% 동일하게 구현했다고 주장하지 않습니다. 전문 게임 아티스트가 만드는 고프레임 연속 스프라이트와 이펙트에는 별도 아트 작업이 더 필요합니다.

## 컴퓨터에서 실행하기

1. Node.js 20 이상을 설치합니다.
2. 이 프로젝트 루트에서 `npm start`를 실행합니다. 추가 패키지 설치는 필요 없습니다.
3. 브라우저에서 `http://localhost:3000`을 엽니다.
4. 첫 쇼케이스에서 **온라인 대전** 또는 **AI 대전** 버튼을 누르세요. 클릭한 버튼은 실질적인 메뉴 기능에 연결되어 있습니다.

### 조작

- A / D: 이동
- W 또는 Space: 점프
- S: 방어, S + W: 아래 발판으로 내려가기
- Shift: 대시
- J: 기본 공격 및 3타 연계
- Q / E / R: 고유 마법
- F: 궁극기
- Enter: 채팅

### AI 대전

첫 화면에서 `AI 대전(싱글)` 선택 → 나의 캐릭터 선택 → 상대 캐릭터 / 난이도 선택 → **AI 아레나 도전하기**.
AI 경기는 실제 서버에서 진행되는 3판 2선승입니다.

### 친구와 대전

첫 화면에서 `온라인 대전` 선택 → 닉네임 / 캐릭터 / 인원 구성 선택 → **온라인 방 만들기** → 방 코드를 복사하여 친구에게 전달 → 친구가 방 코드로 입장 → 정원이 차면 방장이 대전 시작.

## 기존 Render 프로젝트 업데이트하기

1. ZIP을 압축 풀기.
2. 기존 GitHub 저장소에 ZIP 안의 **내용물 전체**를 업로드하고 Commit changes 클릭.
3. GitHub의 첫 화면에서 `package.json`, `server.js`, `game.js`, `public` 폴더가 바로 보여야 합니다.
4. Render > 해당 Web Service > **Settings > Root Directory**: GitHub 최상위에 package.json이 있다면 **공란**.
5. Build Command `npm install`, Start Command `npm start`, Language `Node`, Branch `main`, Plan `Free`.
6. 자동 배포가 없다면 `Deploys > Manual Deploy > Deploy latest commit` 실행.
7. 배포 `Live` 상태 확인 후 기존 주소에서 Ctrl+Shift+R.

## 검증

- Node.js 서버 자동 테스트: **50/50 통과** (`npm test`).
- 정적 서비스 요청 테스트: `/`, `/health`, `/v7-reference.css`, `/v7-reference.js`, `/assets/v7/reference_full.webp`, `/assets/v7/panel_natsu.webp`: HTTP 200.
- 브라우저 화면 및 상호작용 검수: 사용자 레퍼런스 쇼케이스 렌더링, 캐릭터 선택, 모의 서버를 사용한 AI 전투 진입과 온라인 방 생성·대기실 표시 성공.
- 모의 서버의 브라우저 검수는 실제 인터넷 지연이나 여러 사용자의 동시 플레이를 입증하지 않습니다. 이전과 마찬가지로 출시 전 여러 기기에서 실제 플레이 검증이 필요합니다.

## 파일 구성

- `server.js`, `game.js`, `arena-map.js`, `socket.js`: 서버 게임 로직
- `public/index.html`: 화면 전체 HTML
- `public/v7-reference.css`, `public/v7-reference.js`: 새 인터랙티브 레퍼런스 UI
- `public/game-client.js`: 기존 서버 연동/실시간 전투
- `public/assets/v7/`: 제공받은 이미지 기반 UI 자산 (필요한 원본 화면 조각 포함)
- `tests/`: 서버 자동 테스트

## 음악·음성

페어리테일 원작 한국어 더빙 및 원작 메인 테마는 프로젝트에 포함되지 않습니다. 승인된 음성 / 음원 파일을 `public/assets/audio/`에 추가하여 연결할 수 있습니다. 현재 포함된 임시 BGM은 기존 프로젝트의 오리지널 임시 트랙입니다.
